VITAFIT - FITNESS & WELLNESS WEBSITE
======================================

Technology:
- HTML5
- CSS3 only
- No JavaScript
- No PHP
- No database
- No XAMPP required

FILES:
index.html       Home page
workouts.html    Workout library and weekly plan
nutrition.html   Nutrition guidance
wellness.html    Wellness and breathing section
tracking.html    Static habit/progress dashboard
about.html       About page
css/style.css    Complete responsive styling

HOW TO RUN:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. Use the navigation menu to visit all pages.

IMPORTANT:
The website is static. The tracking page is a visual demo; checkboxes do not save data because JavaScript/backend is intentionally not included.

You can upload the entire extracted folder to GitHub Pages, Netlify, Vercel static hosting, or another static web host.
